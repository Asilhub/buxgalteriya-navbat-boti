# 🤖 Бухгалтерия Навбат Боти (CRM & Helpdesk)

Ушбу лойиҳа бухгалтерия хизматлари (Шартнома, Ҳисоб-фактура, Ишончнома) учун мижозлардан ариза қабул қилиш, кунлик навбат рақамини бериш ва гуруҳдаги ходимлар учун тўлиқ интерактив CRM бошқарув тизими ҳисобланади.

---

## ✨ Асосий имкониятлар:

1. **📱 Телефон орқали тезкор рўйхатдан ўтиш:**
   - Бир марта тугма босиб ёки рақам ёзиб рўйхатдан ўтиш.
   - Рақамни исталган вақт ўзгартириш имконияти.

2. **🏢 СТИР (ИНН) ва Изоҳ бириктириш:**
   - Хизмат танлангач, мижоз корхона СТИР рақами ёки ҳужжат изоҳини ёзиб қолдиради (ёки ўтказиб юборади).

3. **🎫 Кунлик автоматик навбат тизими:**
   - Ҳар куни навбат рақамлари `#1` дан бошлаб автоматик берилади.
   - Мижозга тасдиқ хабари чиқарилади.

4. **👨‍💻 Гуруҳда Интерактив CRM Бошқарув:**
   - Гуруҳга келган ҳар бир ариза тагида Inline тугмалар:
     - `[ 👨‍💻 Қабул қилиш ]` va `[ ❌ Бекор қилиш ]`
   - Ходим "Қабул қилиш" босганда:
     - Карточка ҳолати: *«Жараёнда | Масъул: [Ходим исми]»* га ўзгаради.
     - **Мижознинг шахсийсига автоматик хабар боради**: *«Сизнинг #N аризангизни мутахассис [Ходим] кўриб чиқмоқда»*.
   - `[ ✅ Бажарилди ]` босилганда:
     - Мижозга якуний тасдиқ ва **⭐ Хизматни баҳолаш (1-5)** тугмалари юборилади.

5. **📊 «Менинг навбатим» мониторинги:**
   - Мижоз ўз аризаси ҳолати ва олдида неча киши навбатда турганини кўра олади.

6. **⏰ Иш вақти эслатмаси:**
   - Иш вақтидан ташқари пайтда (18:00 дан кейин ёки дам олиш кунлари) мижозга дўстона огоҳлантириш чиқарилади.

7. **📥 Excel / CSV Ҳисобот ва Статистика:**
   - `/stat` — Бугунги ва умумий аризалар статистикаси, ўртача баҳо.
   - `/report` ёки `/excel` — Барча маълумотларни тўлиқ Excel (UTF-8 CSV) файли кўринишида гуруҳга юклаб бериш.

## 🚀 Ишга тушириш:

### 1. Токен ва Гуруҳ ID созламаси (.env)
[.env](file:///home/asilbek/Projects/telegram_bots/Jamoldn%20aka/.env) файлида бот токени ва бухгалтерия гуруҳи ID сини кўрсатинг:
```env
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
GROUP_ID=-100XXXXXXXXXX
```

### 2. Long Polling орқали ишга тушириш:
```bash
php bot.php
```

### 3. Webhook (HTTPS) орқали ишга тушириш:
```bash
php set_webhook.php set https://SIZNING-DOMEN.uz/bot.php
```
